## What it means
- The safety net works: the adaptive bot always lands between its allowed settings and never does anything new, so it can't blow up.
- But it doesn't learn anything useful: last year's better setting is not reliably next year's, so following it lands in the middle, a little better than the default on the design coins and worse on new coins. It also never beats simply using the setting that passed the full test (Donchian is already live with pyramiding: +152%).
- Same conclusion as F8 (AI filter, drawdown brake): the bots keep learning through journaled live results and tested reviews, not by switching themselves.
