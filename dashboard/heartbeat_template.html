How to read the strip

  • Healthy uptrend: each beat peaks higher and each dip stops higher. Up, down, up, like a steady pulse.
  • BOS = the pulse keeps going the same way. MS = the rhythm flips. A body closed past MUST HOLD.
  • Read top-down: 4H first, then 1H, then 15m. The small strip is made of the big one's beats.
  • Shaded band = the current leg. Red half is premium (sell side), green half is discount (buy side).
